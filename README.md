# Hamster Rocket (demo)

A free browser mini-game: a cartoon hamster in a rocket-powered hamster wheel. Tap to boost. Works on mobile and PC, fully offline, with your best score saved locally in your browser.

Just a game for fun. No prizes, no rewards, no tokens to win.

Play: https://botgrok558-ux.github.io/hamster-rocket-demo/
